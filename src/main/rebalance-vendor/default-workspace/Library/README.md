# RebalanceBAP Library

This folder contains the launcher-facing library metadata generated by the mod.

- `Blocks.index.json` lists reusable building blocks such as HP, cooldown, damage, speed, icon, and pool edits.
- `Effects.index.json` groups broader gameplay effect families and their common fields.
- `Icons.index.json` expands the game icon catalog with preview paths when a texture could be resolved.
- `Templates.index.json` lists safe starting templates from generated passives and items.
- `AllOptions.index.json` is the exhaustive searchable library view built from runtime docs, child behaviour targets, and discovered arena assets.
- `Collections.shared.json` stores shared library collections such as favorites or starter buckets that packs may export.

These files are regenerated locally and are not intended to be hand-authored.
